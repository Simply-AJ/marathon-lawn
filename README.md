# Marathon Lawn

Conversion-focused website for Marathon Lawn, serving Scott County and Dakota County, Minnesota.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
npm start
```

## Site goals

The site is built around Marathon Lawn's core offer: reliable recurring lawn care, upfront pricing, one dedicated operator, and a fast free-quote path for homeowners in Scott and Dakota County.

Business details and pricing are based on the supplied Marathon Lawn build brief and current service information.
